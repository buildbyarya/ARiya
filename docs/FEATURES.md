# Satella Features

> This document describes the purpose, behavior, rules, and future plans for every feature in Satella.
>
> It explains WHAT a feature should do, not HOW it is implemented.

---

# Park

## Purpose

The Park is the lobby before entering a Home.

It exists to let users:

- Create a Home
- Join a Home
- Receive an invite code
- Wait for their partner

## Rules

- Users without a Home always land here.
- Users already inside a Home skip the Park.
- Waiting Room no longer exists.
- The Park is responsible for the entire onboarding experience.

---

# Home

## Purpose

The Home is the shared digital house.

Every feature inside Satella should feel like another room inside the Home.

Current modules:

- Watch Together
- Music
- Chat
- Notes
- Gallery
- Games
- Calendar

---

# Watch Together

## Purpose

Allow couples to watch YouTube together.

## Solo Mode

Without inviting a partner:

Works exactly like normal YouTube.

Nothing changes.

## Shared Mode

After inviting a partner:

Playback becomes synchronized.

Current synchronization goals:

- Play
- Pause
- Seek
- Video changes
- Timestamp

Future:

- Shared Queue
- Playlist playback
- Autoplay

---

# Library

Purpose:

Store every saved video.

Current planned sections:

- Watch Later
- Liked Videos
- Playlists
- History (future)

The Library should become one reusable system.

---

# Watch Later

Purpose:

Save videos for later.

Rules:

- Add videos.
- Remove videos.
- Prevent duplicates.
- Behaves like a protected playlist.

---

# Liked Videos

Purpose:

Automatically collect liked videos.

Rules:

- Cannot be renamed.
- Cannot be deleted.
- Only videos can be removed.

---

# Playlists

Purpose:

Allow users to organize videos.

Rules:

Users can:

- Create
- Rename
- Delete
- Add videos
- Remove videos

Future:

Shared playback.
